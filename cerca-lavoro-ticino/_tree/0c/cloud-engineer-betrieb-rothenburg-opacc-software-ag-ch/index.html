Homepage Cloud Engineer (operazione) Rothenburg, Svizzera Con chi lavori? Come parte del nostro Opacc Cloud Service Team, automatizza e standardizza la nostra fornitura di servizi nel Cloud Center. Lavori con i nostri project manager, sviluppatori e ingegneri di sistema. La tua vita quotidiana Dopo una conoscenza completa presso il campus di Rothenburg, supporti il team nelle seguenti aree:

  • Supporto dei nostri sistemi clienti nel Centro Cloud Opacc
  • Installare e aggiornare i nostri sistemi/applicazioni nel Centro Cloud Opacc
  • Monitoraggio dei sistemi
  • Trattamento degli incidenti
  • Aiuta a sviluppare il nostro Opacc Cloud Center

Il tuo sfondo Per completare questo compito con successo, si portano i seguenti:

  • Formazione tecnica sonora e esperienza pratica nell'ambiente IT
  • Ottima conoscenza di Windows e Linux
  • Buona conoscenza delle infrastrutture dei server e delle tecnologie di rete
  • Godetevi il contatto con i nostri clienti Opacc Cloud
  • Divertimento del lavoro in un team e alta competenza di problem solving
  • Prontezza per le missioni serali per mantenere i nostri sistemi clienti aggiornati
  • Collaborazione nella nostra organizzazione 7x24 Pikett
  • Motivazione per imparare nuove e assumersi la responsabilità
