Informazioni su DELVITECH

Delvitech è all'avanguardia nel progresso tecnologico, avendo pionierizzato l'innovativa tecnologia Automatic Optical Inspection (AOI) per circuiti stampati assemblati (PCB) utilizzando l'intelligenza artificiale. Il nostro team è guidato da un impegno per superare i confini tecnologici e fornire risultati eccezionali. Siamo attivamente alla ricerca di individui che sono desiderosi di abbracciare le sfide, contribuire in modo proattivo al raggiungimento dei nostri obiettivi impostati, e svolgere un ruolo cardine nel promuovere la crescita dell’azienda. Attualmente esiste un'opportunità per un esperto e motivato Ingegnere del software di Front-End

DESCRIZIONE DELLA JOB

Siamo alla ricerca di uno sviluppatore di Front End SW dedicato e altamente qualificato / Front End Sviluppatore. Il Front-End Engineer è responsabile per lo sviluppo e l'implementazione dell'interfaccia utente delle applicazioni web e del software. Lavora a stretto contatto con designer UX/UI e sviluppatori back-end per creare esperienze utente intuitive e ad alte prestazioni. Il ruolo consiste nella scrittura di un codice efficiente, nell'ottimizzazione delle prestazioni, nell'assicurare la compatibilità del cross-browser e nella gestione delle interazioni degli utenti. È responsabile della cura della struttura delle informazioni laterali del server. Back Side Engineers scrivono principalmente script di server e API di essere utilizzato da ingegneri del lato anteriore e progettisti UX. Il giorno per giorno consiste nell'ottimizzazione di server per velocità e stabilità, nell'implementazione di strutture di sicurezza, nella generazione di librerie di codice riutilizzabili e nella generazione di soluzioni di archiviazione dati per unire il nostro team. Questo ruolo ha sede nella nostra sede a Mendrisio. Il candidato ideale porterà un approccio paziente, organizzato e problem solving al loro lavoro e deve avere esperienza precedente in un campo simile.

RISPOSTE DI LAVORO

  • Progettare e sviluppare interfacce utente moderne e reattive utilizzando HTML, CSS e JavaScript;
  • Implementare componenti UI utilizzando framework come React, Vue.js, o Angular;
  • Collabora con il team UX/UI per trasformare i progetti in esperienze interattive funzionali;
  • Ottimizzare le prestazioni dell'applicazione per garantire una navigazione fluida e veloce;
  • Assicurare la compatibilità cross-browser e cross-platform;
  • Applicare i principi di accessibilità (WCAG) per garantire l'inclusione e l'usabilità;
  • Integrare API e servizi back-end per il recupero e la gestione dei dati;
  • Implementare test automatizzati per garantire la stabilità del codice e mantenere la qualità;
  • Contribuire alla creazione e manutenzione di librerie di componenti UI riutilizzabili;
  • Collabora con il team di sviluppo per migliorare i processi di codifica e le migliori pratiche.

PRESCRIZIONI

  • Laurea magistrale o dottorato in informatica, ingegneria del software o esperienza equivalente;
  • Esperienza nello sviluppo front-end e costruzione di interfacce utente scalabili;
  • Conoscenza approfondita di:
  • HTML5, CSS3 (SASS/LESS), JavaScript (ES6+);
  • Quadri/Biblioteca front-end (React, Vue.js, Angular)
  • Responsive Design e CSS framework (Tailwind, Bootstrap, Materiale UI);
  • Gestione statale (Redux, Vuex, Zustand, Recoil);
  • Ottimizzazione delle prestazioni Web (Carico pigro, Spalato codice, Caching);
  • Test e debug (Jest, Cypress, React Test Library);
  • Controllo versione: Git, GitHub/GitLab/Bitbucket;
  • CI/CD e DevOps per front-end (Vercel, Netlify, GitHub Actions).
  • Apri la mente e la capacità di lavorare in un team multidisciplinare;
  • Problem solving competenze e capacità di ragionamento;
  • Capacità di attenzione ai dettagli;
  • Automotivata da uno spirito pionieristico creativo;
  • Capacità interpersonali;
  • Capacità comunicative orali e scritte;
  • Deve lavorare bene in team con altre discipline di ingegneria, tra cui elettrico, elettronico, ottico e software.
