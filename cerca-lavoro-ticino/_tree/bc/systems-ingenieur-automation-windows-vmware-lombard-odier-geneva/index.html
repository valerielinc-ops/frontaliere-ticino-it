Sistemi Engineer – Automazione (Windows/VMware)

Siamo alla ricerca di un Windows Systems Engineer con una forte passione per l'automazione e l'ottimizzazione delle infrastrutture. Ti unirai a un team dinamico di 15 esperti di ingegneria del sistema che gestiscono un'infrastruttura globale di oltre 7.000 server. Questo è un ambiente tecnico su larga scala in cui competenze, innovazione e automazione avanzata sono al centro della nostra missione. Si svolgerà un ruolo chiave nell'evoluzione e nella standardizzazione del nostro paesaggio IT, con un forte focus su PowerShell, VMware Aria/vRealize Automation e tecnologie Windows come Windows Server e Active Directory. Sarete coinvolti nella progettazione, realizzazione e manutenzione di soluzioni di automazione finalizzate a migliorare l'efficienza operativa e ridurre l'intervento manuale. Incoraggiamo attivamente l'innovazione e la proposta di nuove idee per migliorare le nostre piattaforme. Stiamo attualmente guidando diverse iniziative strategiche, tra cui l'aggiornamento a VMware Cloud Foundation 9 (VCF 9) per modernizzare il nostro stack di virtualizzazione, così come un progetto di osservabilità di nuova generazione basato su soluzioni Elastic.

Il tuo!

  • Progettare, sviluppare e mantenere gli script PowerShell avanzati per automatizzare le attività di amministrazione del sistema.
  • Distribuire, mantenere e ottimizzare i workflow e i progetti VMware Aria / vRealize Automation.
  • Partecipa all'amministrazione e all'evoluzione delle piattaforme Windows, tra cui Windows Server, Active Directory / ADFS / GPO, SCCM (Microsoft Endpoint Configuration Manager).
  • Contribuire all'adozione delle pratiche Infrastructure as Code (IaC).
  • Assicurare prestazioni, sicurezza e affidabilità in infrastrutture virtuali e fisiche.
  • Collabora a stretto contatto con i team di rete, sicurezza e sviluppo per integrare soluzioni di automazione in tutta l'organizzazione.
  • Sostenere gli sforzi di industrializzazione, le migrazioni e i progetti di miglioramento continuo.

Il tuo progetto

  • Ottimo comando dell'amministrazione di Windows Server.
  • Ottimo comando di PowerShell (scrittura, moduli, API, end to end automation).
  • Buon comando di VMware Aria / vRealize Automation (vRA, vRO, blueprint, workflow). La conoscenza di altri componenti della suite Aria è considerata un bene.
  • Conoscenza delle tecnologie di virtualizzazione (VMware vSphere).
  • Conoscenza delle Infrastrutture come Codice (IaC), CI/CD applicata all'automazione, alle API REST e alle integrazioni di sistema
  • L'esperienza con Azure, Terraform, GIT e Ansible è considerata una risorsa.
  • Forte mentalità problem-solving e continuo orientamento di miglioramento.
  • Capacità di lavorare in modo indipendente in un ambiente complesso.
  • Forte orientamento al servizio e ottime capacità di comunicazione.
  • Approccio analitico e pratiche di documentazione rigorose.
