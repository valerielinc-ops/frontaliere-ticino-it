Full Stack Software Engineer Location: VISP, Switzerland Hybrid Working – 4 days on site, 1 day working from home. We are looking for a Full Stack Software Engineer to design and build scalable digital and data-driven solutions supporting advanced synthesis from research through to manufacturing. This role combines application development, data engineering, and cloud (Azure). You will work on real-world systems integrating laboratory, automation, and enterprise data in a regulated environment. What you will get:

  • An inclusive and ethical workplace

  • A variety of benefits dependent on role and location. The full list of our global benefits can be also found on https://www.lonza.com/careers/benefits What you will do:
  • Design and develop end-to-end applications (frontend + backend) for digitalization and automation use cases
  • Build APIs, services, and user interfaces that support scientific and operational workflows
  • Deliver production-grade, maintainable, and scalable code
  • Integrate across systems such as automation platforms, MES, and lab environments
  • Work with modern data technologies (e.g., Azure Data Lake, Cosmos DB)
  • Deploy and manage applications and data solutions in Azure What we are looking for
  • Strong experience in full stack development (e.g., Python, C#, JavaScript)
  • Experience building APIs, microservices, and modern web applications
  • Experience with Azure services (e.g., Data Lake, Cosmos DB, App Services)
  • Understanding of data pipelines, data modeling, and integration
  • Familiarity with Linux and Windows environments
  • Strong problem-solving skills
