Riguardo al lavoro Abbiamo bisogno di qualcuno che sia altrettanto a suo agio nello scrivere C e JavaScript. Il team Bare crea e mantiene il runtime stesso insieme a un ecosistema in crescita di moduli nativi (bare-bluetooth, bare-tcp, bare-fs, bare-crypto e molti altri). Scriveresti componenti aggiuntivi nativi che collegano le API della piattaforma a JavaScript, eseguono il debug su più sistemi operativi e aiutano a mantenere il runtime piccolo e corretto. Questo è un ruolo pratico nei sistemi. Lavorerai in modo indipendente, possiederai moduli end-to-end e fornirai codice che funziona su telefoni, laptop, server e dispositivi vincolati.

Sviluppo di moduli nativi

  • Progettare, implementare e distribuire moduli nativi bare* (ad esempio, bare-bluetooth, bare-tcp, bare-fs, bare-crypto) end-to-end, inclusi codice e test
  • Scrivere componenti aggiuntivi nativi C che collegano le API della piattaforma (Bluetooth, rete, file system, crittografia) in JavaScript
  • Mantenere ed estendere i moduli nativi esistenti in base alle richieste del team di prodotto e all'elenco di compatibilità dei nodi nudi

Build multipiattaforma e CI

  • Configurare e gestire build multipiattaforma per macOS, Linux, Android (NDK) e iOS (Xcode)
  • Propria configurazione della toolchain di compilazione incrociata per ciascuna piattaforma di destinazione
  • Mantenere pipeline CI che creano e testano moduli nativi su tutte le piattaforme supportate
  • Indagare e correggere errori di build specifici della piattaforma e problemi della toolchain

Contributi bare runtime

  • Contribuire al core runtime Bare (sistema di moduli, sistema di componenti aggiuntivi nativi, thread leggeri)
  • Contribuire a ridurre la superficie API mancante dei nodi nudi
  • Partecipare alla valutazione e all'integrazione di motori JS alternativi, ad esempio libjerry

Debug e qualità

  • Eseguire il debug dei problemi dei componenti aggiuntivi nativi su più sistemi operativi e dispositivi target, inclusi i dispositivi mobili
  • Scrivere e mantenere test per tutti i moduli

Collaborazione e comunicazione

  • Rispondere alle richieste del team Bare da parte dei team interni e del pubblico.
  • Comunicare i progressi, gli ostacoli e le decisioni per iscritto.
  • Partecipare a una chiamata di stato settimanale.
  • Partecipare ai workshop Bare e contribuire ai materiali di onboarding.
  • Coordinarsi con i team di prodotto (Keet, WDK/Wallet).
  • Forti capacità di programmazione C, inclusa esperienza nella scrittura e nel debug di codice nativo su più piattaforme.
  • Competenze JavaScript avanzate con una solida conoscenza degli interni di Node.js e dell'ecosistema dei moduli.
  • Esperienza nella creazione di componenti aggiuntivi nativi per Node.js o runtime simili (N-API, node-gyp o equivalente).
  • Familiarità con libuv o altri framework I/O asincroni.
  • Comodità nel lavorare con toolchain di creazione macOS, Linux, Android e iOS.
  • Esperienza con la compilazione incrociata e API di sistema specifiche per piattaforma (Bluetooth, rete, file system).
  • Capacità di leggere e navigare in codebase C e C++ di grandi dimensioni.
  • Stile di lavoro autodiretto con forti capacità di comunicazione scritta.
