Descrizione completa

Missione

  • Prendere la proprietà dell'applicazione tariffaria e condurre un processo strutturato di trasferimento della conoscenza con lo sviluppatore Java in pensione.
  • Progettare, implementare e gestire servizi backend e API utilizzando Java 17/11/8, Primavera 4/5 e Spring Boot 2.x/3.x.
  • Costruire e mantenere le API REST e SOAP; gestire gli strati HTTP e le specifiche API utilizzando OpenAPI/Swagger.
  • Sviluppare console di front-end e amministrative di supporto in Vue.js o Angular dove pertinenti alle operazioni della piattaforma.
  • Integrare con Oracle e Microsoft SQL Server utilizzando JPA/Hibernate; contribuire SQL e PL/SQL e gestire le modifiche dello schema tramite Liquibase.
  • Implementare e mantenere YAML-based CI / CD con Maven e Git, tra cui porte di qualità e test automatizzati.
  • Applicare modelli di autenticazione e autorizzazione sicuri, tra cui Kerberos e OAuth2/OIDC, e seguire le best practice di AppSec come la guida OWASP, la validazione degli input e la gestione sicura dei segreti.
  • Contribuire a testare la strategia e l'automazione utilizzando JUnit 5, Mockito, Cucumber for BDD/ATDD, e Jest per i test delle unità di front-end.
  • Supporta le operazioni di produzione tramite la risoluzione dei problemi, analizzando le prestazioni e migliorando l'affidabilità.
  • Documento API, decisioni di architettura, runbook, procedure operative e conoscenza delle applicazioni; tracciare il lavoro in JIRA.
  • Collabora con applicazioni, piattaforma, QA, sicurezza e stakeholder aziendali per allineare l'architettura del software con obiettivi aziendali e standard di piattaforma.

Responsabilità chiave durante il trasferimento di conoscenza

  • Costruire una chiara comprensione delle regole aziendali dell'applicazione tariffaria, della logica dei prezzi e delle tasse, delle integrazioni, del modello di dati, del modello di distribuzione e delle dipendenze operative.
  • Acquisire conoscenze non documentate, limitazioni note, incidenti ricorrenti, procedure di supporto e passaggi critici di risoluzione dei problemi.
  • Rivedere il codice sorgente esistente, la documentazione di architettura, oggetti di database, pipeline CI/CD, monitoraggio e processi di rilascio.
  • Stabilire e mantenere runbook pratici per la risposta agli incidenti, distribuzione, rollback, guasti batch o interfaccia, e problemi di produzione comuni.
  • Identificare il debito tecnico, i rischi operativi, le lacune di sicurezza e le opportunità per migliorare la manutenbilità e la resilienza.
  • Diventa un punto di contatto affidabile per il team Account & Fees e i relativi team di supporto dopo la transizione.

Qualifiche chiave

  • 7–15 anni di esperienza professionale di ingegneria del software, con un collaudato record di sistemi di produzione.
  • Forte esperienza di sviluppo backend con Java 8 o versioni successive
  • Java 17 o l'ultima LTS è l'obiettivo di tutte le applicazioni.
  • Esperienza pratica con Primavera 4/5 e Stivale Primavera 2.x/3.x.
  • Prova a progettare e mantenere le API REST e SOAP, gli strati HTTP e le specifiche OpenAPI.
  • Esposizione a Vue.js o Angular per interfacce utente operative e amministrative.
  • Esperienza con Oracle e Microsoft SQL Server, tra cui JPA/Hibernate, SQL, basi di dati di performance, Liquibase e PL/SQL di livello principiante.
  • Esperienza pratica di CI/CD e DevOps con Git, Maven, pipeline basate su YAML e integrazione di automazione di test.
  • Conoscenza di Kerberos e OAuth2/OIDC, insieme alle pratiche di codifica e AppSec sicure che coprono SQL injection, XSS, RCE, validazione degli input e gestione dei segreti.
  • Esperienza con JUnit 5, Mockito e Cucumber per BDD/ATDD; esperienza Jest per il test delle unità di front-end.
  • Capacità di comprendere l'architettura del software e documentarla chiaramente.
  • Inglese fluente; francese è utile.
  • Organizzato, affidabile nel supporto di produzione, e in grado di comunicare chiaramente tra le squadre.

Bello da avere

  • Esperienza con i motori di regola o gli strumenti BPMN, come Drools; livello di principiante è accettabile.
  • Node.js esperienza per attrezzature o servizi ausiliari.
  • Esperienza di test end-to-end con Cypress, Protractor, Selenium WebDriver, o Playwright.
  • API o esperienza di test di carico con JMeter; la disponibilità dello strumento può variare in base all'ambiente.
  • Familiarità con strumenti di scansione vulnerabilità come Checkmarx o Fortify.
  • Forte sensibilità alla qualità del codice, regole Sonar, codice pulito e linee guida OWASP.
  • Esperienza di lavoro in ambienti regolamentati, preferibilmente servizi bancari o finanziari.

Mindset e soft skill

  • La mentalità di proprietà e la soluzione dei problemi pratica sotto vincoli di produzione.
  • Comunicazione chiara e collaborazione efficace con sviluppatori, QA, sicurezza, piattaforma e stakeholder aziendali.
  • Attenzione ai dettagli in sicurezza, documentazione, disponibilità operativa e qualità del codice.
  • L'approccio pragmatico al processo, con comfort operativo in un ambiente che non può avere piena maturità agile.
  • Curiosità e volontà di imparare il dominio aziendale e preservare la conoscenza delle applicazioni critiche.
