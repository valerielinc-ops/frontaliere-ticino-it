La posizione

Descrizione del lavoro

L'Ingegnere di Front End – Clinical Study Design si trova all'incrocio tra l'ingegneria di frontend, i flussi di lavoro clinici e il design del prodotto, aiutando a costruire lo Studio Designer, un prodotto digitale che trasforma come gli studi clinici sono progettati. Questo ruolo combina forti competenze ingegneristiche di frontend, un occhio per l'usabilità e la curiosità tecnica per tradurre complessi flussi di lavoro clinici in interfacce utente intuitive e ad alte prestazioni. Il candidato ideale è curioso, collaborativo, AI-minded, e appassionato di creare interfacce che rendono più intelligente, più veloce, e più efficace progettazione di studi clinici possibile per le persone che li utilizzano ogni giorno.

Responsabilità chiave

  • Progettazione e costruzione di componenti UI altamente interattivi e visivamente distinti utilizzando Angular 14-19+ con architettura standalone
  • Costruisci componenti UI modulari e sistemi di progettazione riutilizzabili.
  • Traduci concetti di design astratti o ambigui in interfacce lucido, pronte alla produzione
  • Scrivere codice pulito, sicuro di tipo in TypeScript , in stile con CSS/ moderno SCSS
  • Gestire flussi di dati asincroni complessi utilizzando RxJS
  • Implementare flussi di autenticazione sicuri utilizzando Angular OAuth2 / OIDC
  • Integra le API RESTful e i servizi GraphQL con applicazioni front-end.
  • Costruire ed evolvere un sistema di libreria/design dei componenti riutilizzabili che bilancia la consistenza con flessibilità creativa
  • Assicurare che le applicazioni siano ottimizzate per prestazioni, accessibilità e usabilità.
  • Gestire flussi di dati asincroni, gestione degli errori e gestione dello stato.
  • Collaborare interfunzionalmente con gli ingegneri backend ( Python/FastAPI/Django), i responsabili dei prodotti e le parti interessate per fornire funzionalità end-to-end
  • Resta aggiornato con le tecnologie di front-end emergenti e le tendenze del settore.
  • Raccomandare miglioramenti ai processi di architettura, framework e sviluppo

Preferiti

  • Istruzione: laurea in Informatica, IT, Ingegneria, o una disciplina relativa.
  • 5-8 anni di esperienza nella produzione UI con Angular (Angular 14-19+, standalone)
  • Forte comando di TypeScript e moderno CSS/SCSS (Grid, Flexbox, animazioni)
  • Esperienza solida con RxJS per la gestione di flussi di dati asincroni
  • Conoscenza delle librerie di visualizzazione dei dati (ad esempio, D3.js, Chart.js, AG-Grid).
  • Esperienza prioritaria che lavora con strutture alternative (React.js, Vue.js) per sostenere iniziative di modernizzazione multipiattaforma.

Responsabilità aggiuntive

  • Esperienza con componenti OAuth2/OIDC angolari per l'autenticazione
  • Esposizione a tecnologie di backend come FastAPI, Django/DRF, o PostgreSQL, abbastanza da collaborare efficacemente con gli ingegneri backend
  • Familiarità con i servizi di base AWS (S3, IAM) o implementazioni basate su cloud
  • Comfort gestione della serializzazione dei dati per le funzioni alimentate dall'IA (ad esempio, strutturazione dei dati per i prompt AI, lavoro con i client HTTP)
  • Comprensione delle strutture di parsing JSON, XML e HTML
  • Esperienza con strumenti di osservazione e monitoraggio come Grafana Faro per il monitoraggio in tempo reale degli utenti
  • Solid Gitlab, esperienza di workflow GitHub (branching, fusione, recensioni PR)
  • Interessi o esperienza di lavoro sulle caratteristiche del prodotto AI/ML
