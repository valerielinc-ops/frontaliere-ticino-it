Descrizione della zona

Responsabilità del lavoro

  • Sviluppare e migliorare applicazioni frontend basate su React.
  • Costruire e mantenere le API backend utilizzando Python e FastAPI.
  • Contribuisci alle applicazioni serverless basate su AWS utilizzando Lambda e API Gateway.
  • Integra i servizi AI/LLM come OpenAI, Claude o AWS Bedrock nei flussi di lavoro aziendali.
  • Supporto implementazione di Retrieval Augmented Generation (RAG) soluzioni e capacità di ricerca vettoriale.
  • Lavora con database come PostgreSQL, DynamoDB e S3.
  • Collabora con gli scienziati dei dati e gli ingegneri senior per integrare i modelli AI nelle applicazioni.
  • Partecipa alle attività di distribuzione CI/CD e applicazioni.
  • Risoluzione dei problemi delle applicazioni e contribuire a migliorare le prestazioni.
  • Segui le migliori pratiche di codifica e cloud sicure.

Qualifiche Istruzione / Esperienza

  • Laurea o Master in Informatica, Ingegneria o campo relativo.
  • da 1 a 5 anni di esperienza di sviluppo software.
  • Esperienza di costruzione applicazioni web utilizzando moderne tecnologie frontend e backend.
  • L'esposizione allo sviluppo cloud-native e alle applicazioni AI-powered è preferito.

Competenze tecniche

  • Frontend: React, TypeScript
  • Backend: FastAPI (Python), AWS Lambda, API Gateway (REST + WebSocket)
  • Ricerca e conservazione: DynamoDB, Aurora PostgreSQL
  • GenAI & RAG: LangChain, OpenAI, Claude, AWS Bedrock
  • DevOps: GitHub Azioni

Dovresti anche avere

  • Forte capacità di programmazione in Python.
  • Esperienza con lo sviluppo di applicazioni basate su React.
  • Comprensione dello sviluppo e dell'integrazione API.
  • Esperienza di sviluppo cloud di base su AWS.
  • Esposizione a tecnologie AI Generative e applicazioni basate su LLM.
  • Comprensione delle migliori pratiche di ingegneria del software.
  • Forte capacità analitiche e di problem solving.
  • Buone capacità di comunicazione e collaborazione.
