Missione

UBP sta subendo una trasformazione dei suoi sistemi tecnologici e ampliando le sue capacità di digitalizzazione. Stiamo quindi rafforzando la nostra Enterprise Solution Architecture Practice. La vostra missione sarebbe quella di guidare la modernizzazione delle nostre iniziative di piattaforma, soluzioni e trasformazione.

Responsabilità

  • Solution Design: Tradurre business Requirement in soluzioni IT scalabili, affidabili e sicure
  • Leadership tecnica: team di sviluppo guida e condurre la transizione a DevOps, Private and Public Cloud e altro ancora
  • Leadership funzionale: Guidare il project manager e condurre la transizione al target Architettura funzionale
  • Stakeholder Management: Comprendere, collaborare e allineare il team trasversale alla stessa visione: Sicurezza, Data Governance, Resilienza Operativa, Protezione dei dati, Legale, Compliance, Functional and System Architects, IT Delivery team
  • Documentazione: Mantenere la documentazione di Enterprise Architecture Repository and Solution Design: Confluence, My-Carto, ecc

Esperienza

  • Corso di laurea o master in informatica, IT o campo relativo
  • 5-10 anni come Solution Architect e/o Tech Lead
  • 5-10 anni Swiss e International Private Banking esperienza e in particolare Wealth Management, Asset Management, Trading, Treasury, Back Office Operation Processs

Certificazione: TOGAF, AWS/Azure/Google Certified Solution Architetto

Competenze tecniche

  • Sicurezza: Sicurezza per Design, Zero Trust Policy
  • Infrastrutture: Physical Baremetal e VMware ESX con vCenter, VM e Kubernetes OpenShift e Microsoft Cloud
  • Architettura aziendale: Open Service Architecture con API e BUS
  • Lingua di programmazione: Java, .Net, Javascript, VueJS, Python
  • Database: Oracle, SQL Server, MongoDB, ElasticSearch
  • DevOps: Azure DevOps, Git, GitHub Copilot (Specification-driven development)
