Dai dati alle decisioni. Dalla piattaforma al valore

A Hilti, i nostri Data Science Interns trasformano dati complessi in approfondimenti significativi che alimentano i nostri prodotti digitali e l'esperienza del cliente. In questo ruolo, progettare esperimenti, costruire modelli e lavorare hands-on con i dati su larga scala per modellare le decisioni aziendali reali. Integrato in una comunità di ingegneria altamente qualificata, otterrai un’esposizione end-to-end, dai test di ipotesi alle soluzioni pronte alla produzione, senza le barriere tipiche dei processi lenti o l’impatto limitato.

Questa è una posizione di tirocinio a tempo pieno. La data di inizio è flessibile. Durata per almeno 6 mesi. Nessun viaggio è previsto per questa posizione.

Cosa porterai

  • Iscritti in una laurea o Master in Scienza dei dati, Scienza informatica, Ingegneria, Matematica, Fisica, Statistica, o simili durante tutta la durata di stage
  • Esperienza pratica con Python e SQL con esposizione a piattaforme cloud come Azure o AWS
  • Conoscenza di base delle pratiche di ingegneria del software (ad esempio basi di architettura, controllo delle versioni, CI/CD).
  • Capacità di comunicare chiaramente analisi complesse
  • Set mentale per risolvere problemi strategici
