Entrate nella nostra squadra!

Nell'area di Infrastructure & Operations, ci occupiamo di tutte le questioni operative di Raiffeisen IT. Il gruppo Windows Server & CCI è responsabile del funzionamento regolare 7*24 dei numerosi server di Windows in tutto il ciclo di vita, virtualizzato o fisico. Per rafforzare il nostro team nel sito di St. Gallen, stiamo cercando una personalità impegnata e tecnicamente esperta come Senior Windows Server Engineer (m/f/d).

Cosa ti aspetta?

  • Indurimento tramite Criteri di gruppo e Gestione della vulnerabilità
  • SCCM Automation – Sequenze di attività, SCOM KnowHow
  • Eccellente capacità analitiche e concettuali, nonché resilienza e assertività
  • Supporto al terzo livello. Pikett 7/24

Cosa porti?

  • Diversi anni di esperienza come ingegnere nell'ambiente Windows Server in ambienti aziendali produttivi
  • Conoscenza degli argomenti OS rilevanti per la sicurezza e la conformità (indurimento, correzioni di sicurezza, norme CIS)
  • mentalità orientata al team, metodi di lavoro auto-responsabili e consapevolezza di alta qualità
  • Conoscenza sicura del tedesco e dell'inglese per l'uso della documentazione tecnica
  • Volontà di cooperare nella 7*24h Picettdienst

"Un ambiente emozionante, stimolante e amichevole vi aspetta." Come Server Engineer Senior, si assume la responsabilità del nostro Windows Server in un ambiente aziendale attraente e professionale con un team consolidato. Richard Zellweger Leader di gruppo Windows Server & CCI Perché Raiffeisen?
