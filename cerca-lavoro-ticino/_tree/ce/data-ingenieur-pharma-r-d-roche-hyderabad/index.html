Descrizione del lavoro

Il Data Engineer – Clinical Study Design si trova all'intersezione dell'architettura dei dati, della scienza clinica e della tecnologia di consegna, aiutando a costruire la base dei dati dietro Study Designer, un prodotto digitale che trasforma come gli studi sono progettati. Questo ruolo combina forti competenze di ingegneria dei dati, una comprensione dei dati e dei flussi di lavoro di studio clinici, e la curiosità tecnica per tradurre complesse strutture di dati clinici in pipeline e modelli affidabili e scalabili che alimentano le intuizioni della piattaforma. Il candidato ideale è curioso, collaborativo, AI-minded, e appassionato di utilizzare i dati per consentire lo studio clinico più intelligente, più veloce e più efficace. Principali responsabilità

  • Costruire oleodotti di ingestione per i protocolli di sperimentazione clinica, documenti ICF, SmPC, CSR e articoli pubblicati (PubMed, CTIS, ClinicalTrials.gov) - gestione di parsing PDF, estrazione di testo e normalizzazione dei dati strutturati
  • Progettare e implementare modelli di dati in Amazon Aurora (relazionale) e GraphDB (grafico di conoscenza) per rappresentare entità di progettazione di prova: endpoint, criteri di ammissibilità, braccia di studio, interventi, aree terapeutiche, e le loro relazioni
  • Sviluppare le tubazioni di embedding e di vettorizzazione per preparare il testo clinico estratto per il recupero basato su RAG nei flussi di lavoro agentici di LangGraph - strategie di strozzatura, arricchimento dei metadati e popolazione del negozio vettoriale
  • Costruisci e mantieni i flussi di lavoro ETL/ELT che trasformano i contenuti clinici non strutturati in dati rigorosi e collegati in entrambi i negozi relazionali e grafici
  • Implementare la convalida della qualità dei dati specifici per i dati clinici - precisione di classificazione della sezione del protocollo, completezza dell'estrazione dell'entità, integrità di riferimento trasversale (ID NCT, numeri EudraCT, termini MeSH)
  • Costruire dati che servono API (Python/FastAPI) che espongono set di dati curati al frontend angolare e strato agente LangGraph
  • Impostare i percorsi di tracciamento e audit dei dati per supportare la tracciabilità normativa delle raccomandazioni di progettazione di prova generate dall'IA

Preferiti

  • Istruzione: laurea in Informatica, Ingegneria dei dati, o una disciplina relativa.
  • 5-8 anni di esperienza costruire piattaforme di dati di grado di produzione e tubazioni.
  • Esperienza con i grafi di conoscenza biomedica (ad esempio, il collegamento dei farmaci - > obiettivi - > malattie -> prove)
  • Lavoro precedente con dati PubMed/MEDLINE, API ClinicalTrials.gov, o dati EMA/CTIS
  • Apache Spark o Databricks per l'elaborazione in batch di grande documento

Competenze richieste

  • Python — Lingua primaria; esperienza con librerie di parsing PDF/documento (PyMuPDF, pdfplumber, unstructured.io, o simili)
  • SQL — Advanced PostgreSQL-compatibile SQL (Aurora); progettazione degli schemi, migrazioni, ottimizzazione delle query, strategie di indicizzazione per volumi di dati clinici
  • Graph Databases — Hands-on con Neptune, Neo4j, o simili; linguaggio di query SPARQL o Cypher; modellazione del grafico ontology/knowledge per entità biomediche
  • AWS — Aurora (PostgreSQL), S3, Lambda, Step Functions, SQS/SNS, IAM; infrastruttura per l'orchestrazione di data pipeline
  • NLP / Elaborazione di documenti — Estrazione di testi da PDF, classificazione delle sezioni, riconoscimento dell'entità chiamato per il testo clinico/biomedico; familiarità con modelli di incorporazione e negozi di vettori (OpenSearch, pgvector, o Pinecone)
  • FastAPI — Costruire dati che servono endpoint; schemi asincroni; integrazione con l'applicazione backend
  • Infrastrutture dati AI/ML — Preparazione dei dati per il consumo di LangChain/LangGraph; progettazione di tubazioni RAG (boccaggio, recupero, riclassificazione); modelli di integrazione dei dati
  • Orchestrazione Pipeline — E
