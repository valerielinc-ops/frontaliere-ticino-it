Descrizione completa

Missione

  • Progettare, implementare e gestire servizi backend e API utilizzando Java (17/11/8), Spring (4/5), e Spring Boot (2.x/3.x).
  • Costruire e mantenere le API REST e SOAP; gestire gli strati HTTP e le specifiche API utilizzando OpenAPI / Swagger.
  • Sviluppare le console front-end/admin di supporto in Vue.js o Angular dove pertinenti alle operazioni della piattaforma.
  • Integrare con Oracle e MS SQL Server utilizzando JPA/Hibernate; contribuire SQL/PL-SQL e gestire le modifiche dello schema tramite Liquibase.
  • Implement CI/CD pipelines (YAML-based) con Maven e Git, tra cui cancelli di qualità e automazione test.
  • Applicare modelli di autenticazione e autorizzazione sicuri (Kerberos, OAuth2/OIDC); seguire le best practice di AppSec (OWASP, validazione degli input, gestione dei segreti).
  • Contribuire a testare la strategia e l'automazione (unità, integrazione, BDD/ATDD con JUnit 5, Mockito, Cucumber
  • Jest su frontend).
  • Operazioni di produzione di supporto: guasti incidenti, analisi delle prestazioni e miglioramenti dell'affidabilità dell'azionamento.
  • Documento API, decisioni di architettura, runbook e procedure operative; tracciare il lavoro in JIRA.
  • Collaborare trasversalmente per allineare l'architettura del software con gli obiettivi aziendali e gli standard della piattaforma.

Qualifiche chiave

  • 7–15 anni di esperienza professionale di ingegneria del software; collaudati sistemi di produzione di record.
  • Forte sviluppo backend con:
  • Java (da 8 a LTS più recente essendo l'obiettivo per tutte le applicazioni)
  • Primavera 4/5 e primavera Boot 2.x/3.x
  • Progettazione API REST e SOAP; fondamentali dello strato HTTP; standard OpenAPI
  • Esposizione frontale con Vue.js o angolare per UI operativi/admin.
  • Databases: Oracle e MS SQL Server, con esperienza pratica in:
  • JPA/Hibernate
  • SQL, fondamentali delle prestazioni DB
  • Liquibase per le migrazioni degli schemi
  • PL/SQL (livello dei bambini, <2 anni)
  • Pratiche CI/CD e DevOps:
  • Git, Maven
  • Gestione delle tubazioni in YAML
  • Integrazione dell'automazione dei test nelle tubazioni
  • Sicurezza e autenticazione:
  • Kerberos e OAuth2/OIDC
  • Buona conoscenza delle pratiche di codifica di AppSec (iniezione SQL, XSS, RCE)
  • Pratiche di prova:
  • JUnit 5, Mockito, Cetriolo (BDD/ATDD)
  • Jest per test unità frontend
  • Nota: il Team non esercita un rigido TDD; l'enfasi è su test pragmatici e automatizzati
  • La competenza dell'architettura del software e la capacità di documentare chiaramente.
  • Lingue: fluente in inglese. Il francese è utile.
  • Competenze morbide: Organizzate, affidabili nel supporto produttivo, in grado di comunicare con chiarezza e collaborare tra i team.

Bello da avere

  • Motori di regola e strumenti BPMN (ad esempio, Drools; principiante <2 anni).
  • Node.js per attrezzature o servizi ausiliari.
  • E2E esperienza di test (Cypress, Protractor, Selenium WebDriver, PlayWright).
  • API/Load testing (JMeter) — Nota: lo strumento potrebbe non essere disponibile in ambiente corrente.
  • Familiarità con strumenti di scansione vulnerabilità (ad esempio, Checkmarx o Fortify).
  • Forte sensibilità alla qualità del codice (regole Sonar/Codice Clean) e linee guida OWASP.
  • Esperienza in ambienti regolamentati (servizi bancari/finanziari).

Mindset e soft skill

  • La mentalità di proprietà e la soluzione dei problemi pratica sotto vincoli di produzione.
  • Comunicazione chiara e collaborazione efficace con sviluppatori, QA e sicurezza.

  • Approccio pragmatico al processo; comfort operativo senza piena maturità agile.
