Descrizione completa

Costruire le interfacce web del software di ispezione AI di Delvitech con React e TypeScript, rendendo i dati complessi semplici per i nostri utenti. Sintesi del lavoro Siamo alla ricerca di uno sviluppatore Frontend / Frontend Engineer con solida esperienza in React e TypeScript per sviluppare interfacce moderne, ad alte prestazioni e ben strutturate per il software di ispezione ottica basato su AI di Delvitech. Principali responsabilità

  • Sviluppa interfacce utente moderne e ad alte prestazioni con React e TypeScript.
  • Progettare componenti riutilizzabili e gestire le prestazioni dell'applicazione (memoization, code splitting).
  • Integra le API REST e GraphQL e gestisci dati asincroni.
  • Collabora con team di design, back-end e QA in un ambiente trasversale.
  • Prestare attenzione ai dettagli e alle prestazioni UX/UI. Requisiti
  • Esperienza solida con React.js: ganci, progettazione dei componenti e gestione delle prestazioni.
  • TipoScript avanzato: digitazione, generici, interfacce e digitazione API/prop.
  • Esperienza con almeno una libreria di gestione dello stato (ad esempio Redux, Redux Toolkit, Zustand, Recoil o simili).
  • Sperimentare REST e GraphQL API e gestire dati asincroni.
  • Familiarità con strumenti di costruzione moderni (Vite, Webpack) e Git.
  • Autonomia, capacità di problem solving e forti capacità di collaborazione. Bello da avere
  • MUI (Material UI) libreria di componenti e sistema di progettazione.
  • Three.js per rendering 3D/WebGL.
  • XState per la gestione dello stato con macchine a stato finito e carrelli di stato.
