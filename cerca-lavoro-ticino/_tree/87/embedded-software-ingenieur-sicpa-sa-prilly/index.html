Descrizione completa

The Embedded Software Engineer is a technical contributor within the Machine-Readable Features Laboratory , supporting the development, integration, validation, and maintenance of embedded software solutions used in advanced machine-readable authentication and traceability systems.

The role covers a broad range of technologies including real-time operating systems (RTOS), embedded Linux platforms, high-speed sensor systems, signal processing, System-on-Chip (SoC) architectures, and industrial software development frameworks . The position combines software architecture and development , system integration, testing, troubleshooting, and deployment activities within a multidisciplinary environment involving electronics, optics, chemistry, data science, and software engineering.

This position is well suited for an engineer seeking to build strong expertise in embedded systems, industrial sensing technologies, and software lifecycle management, with opportunities to contribute from concept to deployment in cutting-edge security solutions.

ROLE

  • Develop, maintain, and optimize embedded software applications in C/C++ for real-time and Linux-based platforms.
  • Design, develop, and maintain software running on RTOS, embedded Linux, microcontrollers, microprocessors, DSPs, and System-on-Chip (SoC) platforms .
  • Support the integration of embedded software with electronics, optics, and sensor subsystems.
  • Design and execute software testing, validation, and troubleshooting activities to ensure performance, reliability, and maintainability.
  • Investigate and resolve software defects, field issues, and system integration challenges.
  • Contribute to software documentation, including requirements, design specifications, test reports, user documentation, and maintenance procedures.
  • Participate in technical reviews, design discussions, and continuous improvement initiatives.
  • Collaborate actively within multidisciplinary project teams including electronics engineers, software engineers, physicists, chemists, and scientists.

PROFILE

Education & Experience

  • Bachelor's or Master's degree in Software Engineering, Computer Engineering, Embedded Systems , or equivalent.

Technical Skills

  • Strong proficiency in C/C++ programming for embedded applications.
  • Experience with Real-Time Operating Systems (RTOS) and embedded Linux environments.
  • Knowledge of software testing methodologies , debugging techniques, and version control systems.
  • Familiarity with System-on-Chip (SoC) architectures , including microprocessors, microcontrollers, and DSPs.
  • Knowledge of communication interfaces and industrial embedded systems integration.
  • Comfortable using standard engineering tools for software development, versioning, issue tracking, and technical documentation.

Personal Skills

  • Curious, motivated, and eager to develop deep technical expertise .
  • Strong analytical and problem‑solving mindset.
  • Increasingly autonomous, with the ability to manage laboratory tasks with limited supervision.
  • Reliable, structured, and quality‑oriented.
  • Team player in a multicultural and interdisciplinary environment .

Languages

  • Good working knowledge of English and French (spoken and written).
