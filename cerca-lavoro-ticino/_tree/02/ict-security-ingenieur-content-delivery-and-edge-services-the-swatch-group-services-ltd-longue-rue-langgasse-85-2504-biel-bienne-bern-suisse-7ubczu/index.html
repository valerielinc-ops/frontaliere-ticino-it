  • ICT Security Engineer (Content Delivery & Edge Services)
  • Description du poste

You will design, implement, and maintain Akamai security and performance solutions to ensure the optimal security and availability of Swatch Group’s digital platforms. You will collaborate with internal teams and external providers to integrate CDN services into our infrastructure, automate workflows, and enhance global content distribution for Swatch Group brands.

  • In this role, you will be responsible to:
  • Design, deploy, and optimize Akamai CDN solutions (Ion, Image Manager, Kona Site Defender, EdgeWorkers) for high availability and low latency;
  • Implement edge caching strategies, traffic offload, and acceleration techniques to improve web performance;
  • Implement and maintain security and bot management rules;
  • Develop and maintain CI/CD pipelines for CDN configuration and automation;
  • Collaborate with application teams to ensure seamless integration of CDN services with enterprise platforms;
  • Manage infrastructure as code (IaC) for CDN and cloud environments using tools like Terraform or Ansible;
  • Monitor and analyze CDN performance metrics, availability, and security posture using Akamai Control Center and analytics tools;
  • Troubleshoot and resolve issues related to CDN security;
  • Ensure compliance with security best practices for CDN and edge deployments
  • Profil

  • Good knowledge of enterprise security technologies: firewalls (Palo Alto, Fortinet), VPN, endpoint protection, WAF;
  • Good knowledge of web application security and CDN integration across digital platforms;
  • Experience with CI/CD tools (Azure DevOps, GitLab CI, CircleCI);
  • Proficiency in IaC tools (Terraform, Ansible) and scripting languages (Python, Bash);
  • Knowledge of web technologies (HTML, CSS, JavaScript, PHP);
  • Experience with monitoring and logging tools (Prometheus, Grafana, Elastic stack);
