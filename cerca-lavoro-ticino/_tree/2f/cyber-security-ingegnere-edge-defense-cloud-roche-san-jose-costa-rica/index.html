L'opportunità

Come Senior Cybersecurity Engineer per Cloud & Edge Defense, sarai l'architetto e ingegnere primario responsabile della sicurezza dei nostri confini digitali globali e degli ecosistemi multi-cloud. La vostra missione è quella di garantire la nostra "porta anteriore" progettando e implementando soluzioni di controllo del traffico ad alte prestazioni in AWS, GCP e Azure utilizzando Palo Alto VM-Series come pilastro centrale. Questo è un ruolo tecnico "implementer" in cui si architetto, progettazione, costruzione e operare infrastrutture di sicurezza della rete cloud.

Le tue principali responsabilità includono

  • Multi-Cloud Infrastructure Design: Progettare e sviluppare robuste infrastrutture di rete cloud in AWS, GCP e Azure, sfruttando le istanze Palo Alto per l'ispezione del traffico profondo.
  • Advanced Palo Alto Engineering: Eseguire la configurazione avanzata e la gestione delle soluzioni Palo Alto (VM-Series, Panorama), tra cui aggiornamenti complessi e migrazioni in produzione.
  • Cloud Programming & Automation: Leverage cloud vendor network infrastructures per configurare e distribuire soluzioni di sicurezza tramite pipeline automatizzate utilizzando Terraform e Python.
  • Esecuzione della funzione: Implementa e gestisci App-ID, User-ID, WildFire, Threat Prevention, SSL Decryption e GlobalProtect per far rispettare una posizione di Zero Trust.
  • Eccellenza operativa: Gestisci le politiche di sicurezza come codice e migliora i flussi di lavoro di automazione e l'orchestrazione cross-platform per eliminare l'attrito manuale.
  • Expertise: Risoluzione dei problemi complessi relativi al routing, al bilanciamento del carico e all'ispezione del firewall in ambienti multi-cloud.

Chi sei

  • Hai una laurea in Informatica, ingegneria del software, sicurezza delle informazioni, o un campo tecnico correlato.
  • Hai una comprovata traccia di implementare i controlli di sicurezza di rete in almeno due principali fornitori di cloud (AWS, Azure, o GCP).
  • Possiedi 3+ anni di esperienza nella configurazione e nel mantenimento di Palo Alto Firewall di prossima generazione (NGFW), tra cui l'ispezione TLS, WildFire e GlobalProtect.
  • Hai dimostrato esperienza utilizzando Ansible, Terraform o Python per gestire l'infrastruttura di sicurezza di rete su scala.
  • Hai una profonda comprensione dei protocolli di base (BGP, OSPF, DNS, TLS/SSL) e come si intersecano con l'applicazione della sicurezza.

Preferito

  • Palo Alto Networks PCNSE, AWS Certified Security o Azure Security Engineer Associate certificazioni.
  • La competenza in Infrastructure come Code (IaC) utilizzando Terraform e GitHub per mantenere le configurazioni di sicurezza controllate dalla versione.
  • Forte capacità di scripting in Python o Go per costruire integrazioni API personalizzate tra piattaforme di sicurezza.
  • Esperienza di lavoro in ambienti altamente regolamentati come Pharmaceuticals, Healthcare, o Finance.
  • Un self-starter con la capacità di gestire i flussi di lavoro tecnici dal concetto alla produzione con una supervisione minima.
