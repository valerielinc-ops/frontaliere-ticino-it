Descrizione completa

Medacta International è alla ricerca di un SQL & BI Developer /Analyst che verrà inserito nel team IT con l'obiettivo di sviluppare e manutenere soluzioni di Business Intelligence e reportistica aziendale.

La risorsa svolgerà le seguenti attività

  • data modeling e trsformazione dati;
  • sviluppo dashboard e analytics (Qlik Sense);
  • progettazione e ottimizzazione di query SQL avanzate;
  • realizzazione di report strutturati (SSRS);
  • gestione e ottimizzazione dell'infrastruttura dati su Microsoft SQL Server;
  • avrà un ruolo chiave nel garantire coerenza, affidabilità e performance dei dati utilizzati a livello globale, intervenendo sia a livello applicativo he infrastrutturale.

Hard Skills

  • Laurea in Informatica;
  • ottima conoscenza della lingua inglese;
  • almeno 3 anni di esperienza in una funzione analoga in ambienti enterprise con elevati volumi dati;
  • esperienza concreta con:
  • T-SQL avanzato
  • stored procedure complesse
  • query tuning e performance optimization
  • esperienza con SQL Server Reporting Services (SSRS);
  • esperienza su Qlik Sense (data load, scripting, dashboard);
  • buona capacità di modellazione dati (star schema, normalizzazione);
  • conoscenza di:
  • execution plan e analisti performance
  • gestione indici e statistiche
  • backup/restore e strategie di recovery
  • monitoraggio SQL Server (DMV, strumenti nativi)
  • esperienza nella gestione di database su grandi volumi di dati.

Soft Skills

  • approccio pratico e orientato alla soluzione;
  • capacità di lavorare su sistemi complessi e dati critici;
  • attitudine al problem solving e alla gestione autonoma delle attività;
  • forte attenzione alla qualità e affidabilità del dato.
