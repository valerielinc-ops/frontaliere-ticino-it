  • Ricercare e sviluppare modelli LLM e/o video o multimodalità all'avanguardia per accelerare il progresso dell'open source nei settori.
  • Implementare l'applicazione di modelli di grandi dimensioni nei nostri scenari aziendali, come pre-formazione, messa a punto supervisionata, post-formazione, inferenza ecc.

  • Esperienza di ricerca correlata in almeno una delle seguenti aree: LLM, visione artificiale, multimodalità
  • Essere esperto con il framework e le librerie di deep learning PyTorch
