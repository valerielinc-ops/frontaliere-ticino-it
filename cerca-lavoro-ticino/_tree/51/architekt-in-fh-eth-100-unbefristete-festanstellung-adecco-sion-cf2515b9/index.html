# Responsabilita' #

  • Sviluppare file tecnici e documenti di implementazione
  • Gestione delle tendenze, delle tendenze e delle tendenze

Profilo

  • Eccellente padronanza del software ArchiCAD e di altri software comuni
  • Buone capacità relazionali e facilità nel trattare con vari interlocutori
  • Mastery of French, con buona conoscenza in inglese e/o tedesco

# Benefits #
