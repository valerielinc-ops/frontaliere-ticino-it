  • Build and execute automated and integration tests using gTest or similar frameworks, applying best practices for code quality, maintainability, and compliance with standards such as EU CRA and IEC 62443.

  • Hands-on experience with hardware debugging, firmware integration, Git, build systems, and structured software development practices.
