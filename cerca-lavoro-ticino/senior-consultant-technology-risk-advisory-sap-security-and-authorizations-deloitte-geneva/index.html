Processo di candidatura

  • You have foundational knowledge of Cyber Security Frameworks and Application Security, with hands-on expertise in managing SAP System Security (e.g. patch and vulnerability management, system parameters, connectivity, technical users, secure code).
  • Experience with SAP Security Software and Tools is a plus.
  • Fluent in English, with the ability to engage effectively with diverse stakeholders.
  • Additional languages, such as German or French, is a plus. What sets you apart
  • You understand the operating models to be put into place for efficient day-to-day SAP security processes.
  • Experience with near- and off-shore models is a plus.
  • Demonstrated experience with artificial intelligence (AI), such as leveraging AI tools or solutions within risk, security, or SAP-related contexts (e.g., AI-driven access control analysis, intelligent risk assessment, automation of security controls).
  • Foundational knowledge of SAP BTP (Business Technology Platform) security, including identity and access management (IAM), API security, and secure integration patterns.
